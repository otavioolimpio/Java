# Desafio POO DIO

> Projeto Java desenvolvido como parte do *Desafio de Programação Orientada a Objetos* da **Digital Innovation One (DIO)** — o objetivo é aplicar, de forma prática, os principais pilares da Programação Orientada a Objetos (POO): **Abstração, Encapsulamento, Herança e Polimorfismo**. 

---

## 🚀 Sobre o Projeto

Este repositório contém a solução do desafio proposto no bootcamp de Java da DIO, no qual criamos um modelo orientado a objetos representando um domínio (como bootcamp, cursos, mentorias, devs etc.) usando Java. Os conceitos de POO são utilizados para estruturar, relacionar e manipular essas classes de forma organizada e coerente.

---

## 📚 Principais Conceitos Aplicados

O projeto foi idealizado para que eu pudesse praticar e compreender os pilares da POO em Java:

- **Abstração** — Representar entidades do domínio com foco apenas nas informações essenciais.
- **Encapsulamento** — Proteger os dados definindo acessos por meio de métodos. 
- **Herança** — Reaproveitar atributos e comportamentos entre classes relacionadas. 
- **Polimorfismo** — Permitir que objetos de diferentes classes relacionadas respondam de formas específicas.
