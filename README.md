# ☕ Repositório de Códigos Java

Este repositório foi criado com o objetivo de **armazenar, compartilhar e demonstrar códigos desenvolvidos em Java**, evidenciando minha capacidade de implementar desde estruturas básicas até operações mais elaboradas utilizando essa linguagem de programação.

Além disso, o repositório também contempla materiais e exercícios desenvolvidos durante o **Bootcamp Accenture – Desenvolvimento Java & Cloud**, organizados de forma estruturada para facilitar o estudo, a revisão e a evolução contínua.

---

## 📌 Objetivos do Repositório

- Demonstrar domínio dos fundamentos da linguagem **Java**  
- Praticar lógica de programação e orientação a objetos  
- Registrar minha evolução técnica ao longo do tempo  
- Centralizar exercícios, testes e pequenos projetos  
- Armazenar conteúdos desenvolvidos no **Bootcamp Accenture – Desenvolvimento Java & Cloud**
